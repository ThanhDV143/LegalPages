# LegalPages — ThanhDV Apps

Static informational website for software and games developed by Thanh Đặng (ThanhDV). The site contains:

- `index.html` — Home page
- `privacy.html` — Website Privacy Policy
- `terms.html` — Website Terms of Service
- `style.css` — Responsive styling

All visible starter placeholders have been replaced. The current legal pages describe this **website**, not the exact data processing of every separate application.

## Important: Google OAuth verification

Google requires the homepage and privacy policy to accurately represent the specific application submitted for review and disclose its use of Google user data. These general website policies **must not be used as a substitute for accurate application-specific disclosures** if an application requests Google API access.

For each app, supply an app-specific description, OAuth scopes, Google user data collected/accessed, purposes of use, storage, retention, deletion methods, sharing, and support contact as applicable. Link to app-specific pages in Google Cloud Console when required.

## GitHub Pages

Repository: https://github.com/ThanhDV143/LegalPages

Go to **Settings > Pages > Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then Save.

After deployment, expected URLs are:

- Home: https://thanhdv143.github.io/LegalPages/
- Website Privacy: https://thanhdv143.github.io/LegalPages/privacy.html
- Website Terms: https://thanhdv143.github.io/LegalPages/terms.html

If you later configure a custom domain, update the URLs accordingly.
